# PRD: Context7-Calibrated Optimization Review

## Goal

Inspect the project and list remaining optimization opportunities with pros,
cons, priority, and evidence.

## Requirements

- Use Context7 when available to calibrate current library/tool guidance.
- If Context7 tools are not exposed in this session, state that limitation and
  continue with local evidence.
- Review project code, specs, tests, quality gates, and packaging state.
- Produce a prioritized optimization list without modifying implementation
  code.
- Leave existing unrelated working-tree changes untouched.

## Acceptance Criteria

- The final response lists concrete optimization items with rationale,
  advantages, disadvantages, and suggested priority.
- Each item is grounded in current project evidence.
- The Context7 availability result is explicitly reported.
