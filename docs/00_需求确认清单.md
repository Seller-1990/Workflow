# 工作流管理需求确认清单（V1 / PySide6 桌面版）

## 一、平台与存储
- 平台：桌面应用（Python + Qt / PySide6）
- 存储：SQLite（本地持久化）
- 目标：个人优先 + 预留内网小团队扩展

## 二、工作流功能（V1 必做）
1) 工作流管理：新建/复制/删除/重命名
2) 步骤类型：Python 脚本 / Excel PowerQuery 刷新 / Power BI Desktop 刷新 / 子工作流
3) 编排能力：依赖、并行、前置步骤、上下移动、复制/删除
4) 运行控制：
   - 全流程运行
   - 从指定步骤开始
   - 只运行指定步骤
   - 重试失败步骤
5) 监控与日志：实时日志、按步骤日志打开、运行历史

## 三、界面结构（最终确认版）
- 左侧：整体可折叠（工作流列表 + 运行控制）
- 中区上部：基础配置（现有字段，折叠）
- 中区中部：
  - DAG 可视化（默认展开，固定高度）
  - 步骤列表（含顺序列 + 行内快捷设置）
- 中区下部：步骤详情编辑器
- 右侧：实时日志 + 运行历史（可折叠）

## 四、步骤列表交互
- 行内快捷设置：依赖/并行/前置均为开关/按钮
- 行内操作：上下移动
- 详情编辑器用于精细配置

## 五、DAG 规则
- 位置：步骤列表上方
- 默认：展开
- 内容：顺序 + 名称 + 依赖连线

## 六、后续扩展（V1.5/V2）
- 产物管理（版本/归档）
- 多人权限与审计
- 任务队列与资源配额
