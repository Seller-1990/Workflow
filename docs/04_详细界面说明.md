# 详细界面说明（V1 / PySide6 桌面版）

## 0. 顶部工具栏
- 新建工作流：创建一个空工作流
- 保存：保存当前编辑的步骤或配置
- 运行：默认“全流程运行”
- 停止：取消当前运行
- 导入 JSON / 导出 JSON：工作流配置导入导出
- 折叠左侧 / 折叠右侧：释放主区域空间

## 1. 左侧面板（整体可折叠）
### 1.1 工作流列表
- 列表项：工作流名称
- 右键菜单：重命名 / 复制 / 删除
- 交互：点击切换工作流，自动刷新中区与右侧

### 1.2 运行控制（四种模式）
- 全流程运行
- 从选中步骤开始
- 只运行选中步骤
- 重试失败步骤
- 交互：选择步骤后再点击对应运行按钮

## 2. 中区上部：基础配置（可折叠）
### 2.1 工作流基础
- 工作流名称
- 图表主题
- 步骤编排开关（启用/关闭）

### 2.2 并行配置
- 启用并行
- 最大并行数

### 2.3 通知配置
- 启用钉钉通知
- Webhook / 关键字 / 消息模板

### 2.4 单脚本模式（当“步骤编排”关闭时启用）
- 单脚本类型（Python / Excel PowerQuery / Power BI Desktop / 子工作流）
- 单脚本路径
- 单脚本参数（JSON 数组）
- 单脚本工作目录

### 2.5 文件夹监听
- 启用监听
- 监听模式（任意变动触发 / 全部目录更新后触发）
- 监听目录（每行一个）
- 扫描间隔（秒）/ 延迟触发（秒）

## 3. 中区中部：DAG + 步骤列表
### 3.1 DAG 可视化（默认展开）
- 节点信息：顺序 + 名称
- 连线规则：按依赖关系绘制
- 作用：快速理解流程结构

### 3.2 步骤列表（核心编辑区）
- 列：顺序 / 类型 / 名称 / 脚本 / 依赖 / 前置 / 并行 / 操作
- 行内快捷：
  - 依赖（默认“依赖上一步”快捷）
  - 前置（开关）
  - 并行（开关）
  - 上移 / 下移 / 删除
- 单脚本模式：仅展示单脚本步骤

## 4. 中区下部：步骤详情编辑器
- 字段：步骤名称、类型、脚本/文件、参数、工作目录、图表主题、超时、重试、前置/并行、依赖选择、目标子工作流
- 子工作流选择：支持搜索过滤 + 最近使用
- 循环依赖：检测到跨工作流循环依赖会弹窗提示
- 交互：保存 / 重置

## 5. 右侧面板（可折叠）
### 5.1 实时日志
- 展示当前运行日志
- 按步骤打开日志（若有）

### 5.2 运行历史
- 显示运行编号、状态、开始时间、时长
- 右键：打开日志目录
