# 架构与模块拆分（简版）

## 1. UI 层（PySide6）
- 负责界面、输入校验、交互流程
- 通过接口调用编排层，不直接执行任务

## 2. 编排层（Workflow Engine）
- 管理步骤顺序、依赖、并行、失败策略
- 对外提供四种运行模式接口

## 3. 执行器层（Executors）
- Python 执行器：运行脚本
- Excel 执行器：触发 PowerQuery 刷新
- Power BI Desktop 执行器：触发刷新
- 预留扩展：新增更多类型

## 4. 数据层（SQLite）
- 工作流配置、步骤配置、运行记录、日志索引
- 预留用户/权限字段（为未来多人扩展）

## 5. 日志与监控层
- 统一日志格式与归档
- 步骤级日志快速打开

## 可迁移性说明
- UI 与执行器解耦，未来可替换 UI（Web/桌面）
- 数据层可平滑迁移到服务端数据库
